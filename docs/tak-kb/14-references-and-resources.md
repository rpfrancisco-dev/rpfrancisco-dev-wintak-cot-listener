## CoT / developer libraries (most relevant to a listener)
- **PyTAK** — https://pypi.org/project/pytak/ — Python module for TAK clients, servers & gateways; CoT & non-CoT handling, serialization, network send/receive.
- **FreeTAKServer** — https://github.com/FreeTAKTeam/FreeTakServer — Python 3 TAK server, EPL.
- **taky** — https://github.com/tkuester/taky/ — simple CoT server.
- **Ampledata.org** — https://ampledata.org/ and https://github.com/ampledata?tab=repositories — TAK/CoT projects (same dev as Sensors & Signals).
- **Sensors and Signals (SnS)** — https://www.snstac.com/ — TAK integration support.
